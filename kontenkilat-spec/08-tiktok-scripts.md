# 08 — 30 TikTok Scripts (Production-Ready)

30 script siap shoot untuk 30 hari launch week & momentum building. Setiap script lengkap dengan hook, visual cue, audio, dan CTA.

**Format setiap video:**
- Durasi: 15-60 detik (varies)
- Aspect ratio: 9:16
- Hook 3 detik (NEVER skip)
- Clear CTA in last 5 detik
- Caption pre-written
- Hashtag set ready

**Posting cadence:** 1 video/hari. Schedule via KontenKilat sendiri (meta!).

## CONTENT PRODUCTION CHECKLIST

Untuk eksekusi 30 video efisien:

### Batch Production (Recommended)

**Sesi 1 (4 jam):** Shoot semua talking head founder scripts (7-8 video)
**Sesi 2 (4 jam):** Screen record semua demo (10-12 video)
**Sesi 3 (3 jam):** Edit + caption + thumbnail (semua 30 video)
**Sesi 4 (1 jam):** Schedule semua via Buffer/Later atau KontenKilat sendiri

**Total: 12 jam = 1.5 hari kerja untuk 30 video full month**

### Asset Library Required

- [ ] 5 background music tracks (varying mood)
- [ ] 20 stock footage clips (industry samples)
- [ ] Logo intro animation (3 detik)
- [ ] Lower-third graphics package
- [ ] CTA end card animation
- [ ] Caption font (Inter Bold + Black)
- [ ] Color palette consistent (teal #00BFA6)

### Posting Schedule

| Hari | Waktu | Script # |
|---|---|---|
| Sen | 12:00 + 20:00 | #1 (12:00), #8 (20:00) |
| Sel | 13:00 + 21:00 | #2 (13:00), #9 (21:00) |
| ...dst | | |

**Best times Indonesia TikTok:**
- 12:00-14:00 (lunch)
- 19:00-22:00 (evening)
- Weekend: tambah 10:00-11:00

### Engagement Strategy

**Per video posting:**
- Pin comment dengan CTA + question
- Reply komentar dalam 30 menit pertama
- Engage dengan 10 video lain dalam jam pertama (algorithm boost)
- Cross-post ke IG Reels dalam 4 jam

### Tracking

Per video track:
- View count (24h, 7d)
- Engagement rate
- CTR ke bio link
- Signup attributed (via UTM)
- Pro conversion attributed

Pakai dashboard PostHog untuk aggregated view.
